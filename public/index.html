BROWSER EXTENSION

Chrome Extension Installation Guide

Load TRACE into Google Chrome in 3 simple steps to analyze messages directly from Gmail and WhatsApp Web.

STEP 1

Open Chrome Extensions

In Google Chrome, navigate to chrome://extensions or click Menu > Extensions > Manage Extensions.

STEP 2

Enable Developer Mode

Toggle the Developer mode switch in the top-right corner of the Chrome Extensions page.

STEP 3

Load Unpacked Folder

Click Load unpacked and select the extension folder inside this project directory.
